# Netflix Data Analysis
This project explores and analyzes a dataset of Netflix movies and TV shows using Python.The goal is to clean the dataset, explore patterns in Netflix content, create visualizations, and identify meaningful insights from the data.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Initial dataset inspection
- Missing-value analysis
- Duplicate-value checking
- Data cleaning
- Movies vs TV Shows analysis
- Netflix content added over time
- Top countries by number of titles
- Content rating distribution
- Genre analysis
- Data visualization

## Dataset

Netflix titles dataset containing information about movies and TV shows including title, type, country, release year, rating, duration and other attributes.

## Key Questions

Some of the questions explored during this project include:
1. How many Movies and TV Shows are available?
2. How has Netflix content changed over the years?
3. Which countries have the most titles?
4. What are the most common genres?
5. What are the most common content ratings?
